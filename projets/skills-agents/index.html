PrivéPythonShellMCP

Environnement IA personnel

Une équipe d'agents dirigée par un orchestrateur, des skills chargés à la demande, des outils branchés par MCP, et un installeur pour tout reposer sur une machine Linux.

Un chef d'orchestre, une liste fermée

L'orchestrateur reçoit la demande, la découpe, délègue chaque morceau à un spécialiste, vérifie ce qui revient et livre une synthèse.

Il n'a le droit de déléguer qu'à une liste fermée d'agents : un agent qui n'y figure pas est refusé. À chaque démarrage de session, un hook rappelle l'équipe du projet en cours ou propose d'en choisir une.

  1. Découperla demande en tâches
  2. Délégueraux agents de la liste
  3. Vérifierles résultats reçus
  4. Livrerune synthèse

Des skills chargés à la demande

Un skill est un dossier d'instructions. Il reste fermé tant qu'on n'en a pas besoin : Claude ne l'ouvre que quand la demande s'y rapporte. L'un d'eux décrit une méthode d'orchestration.

Des outils qui se branchent comme des prises

Trois serveurs MCP sont proposés en option. Chacun expose des outils qu'un agent peut utiliser.

  • Documentation de bibliothèquespour consulter une doc à jour
  • Documentation Microsoftpour les produits et services Microsoft
  • Retouche photoun serveur maison

Un petit widget de bureau, optionnel lui aussi, montre les agents au travail. Il n'écoute que sur la boucle locale.

Un installeur qu'on peut relancer sans crainte

--link pose des liens symboliques vers le dépôt : une modification y est prise en compte tout de suite.

  1. --dry-runmontre ce qui serait fait, sans rien écrire
  2. Sauvegardetout fichier existant qui diffère est mis de côté d'abord
  3. Poseliens symboliques vers le dépôt
  4. Hookfusionné dans les réglages par un outil Python, sans toucher au reste
  5. Manifestela liste de ce qui a été posé

Le désinstalleur s'appuie sur le manifeste : il ne retire que ce que l'installeur a posé. Des tests pytest couvrent l'installeur et le hook.

Rien de secret dans le dépôt

Un dépôt Git garde tout l'historique : un secret commité reste récupérable même après suppression. Aucun jeton, mot de passe ni clé n'entre donc dans le dépôt.

Les réglages propres à une machine, les identifiants et les fichiers générés sont exclus du suivi.

Le code de ce projet est privé : il n'est pas publié.
