Les couches

  1. Formulaires Windows Forms : Login, Main, MessagePrive, Forum
  2. Logique métier Modèles et services : authService, MessageService, ForumService, PasswordHasher, ClientValidator
  3. Accès aux données UserDateAccess, messageDataAccess, ForumDataAccess, LogsDataAccess
  4. Oracle Base et script PL/SQL du dépôt

LogService : une journalisation des actions est prévue, côté métier et en base.

Scène : connexion. L'utilisateur saisit ses identifiants et valide.

Ce que fait le projet

  • Une application de bureau Windows (Windows Forms) de messagerie, avec inscription et connexion.
  • Des messages privés entre utilisateurs, avec le repérage des conversations qui contiennent des messages non lus.
  • Des forums : création, recherche et échange de messages.

Comment c'est construit

  • Une architecture en couches : formulaires, logique métier (modèles et services), puis accès aux données.
  • VB.NET sur .NET Framework 4.7.2, avec le pilote Oracle managé. Un script SQL avec du code PL/SQL est fourni dans le dépôt.
  • Requêtes paramétrées liées par nom, écritures dans des transactions, identifiants tirés de séquences Oracle.
  • Mots de passe hachés avec un sel aléatoire (PBKDF2-SHA256), jamais stockés en clair. Un fichier de tests existe pour ce composant.
  • Un composant de validation contrôle les saisies côté application.
