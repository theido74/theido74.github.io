Image Scanner

Un outil en ligne de commande qui parcourt un dossier, un site web ou un conteneur Azure Blob, reconnaît les images, puis en tire un catalogue en CSV ou en JSON.

Le nom ne suffit pas

Une image se reconnaît à son extension, à ses premiers octets (la « signature »), ou aux deux. Trois fichiers d'exemple montrent pourquoi lire les octets change le résultat.

Le rapport CSV contient une colonne « Magic Verified ». Le README ne détaille pas la règle exacte du mode « both » : le tableau montre donc les deux indices côte à côte.

Vitesse annoncée

Le README donne des ordres de grandeur « sur un matériel typique ». Ces chiffres viennent du dépôt : ils n'ont pas été remesurés pour cette page.

Le parcours local répartit le travail sur les cœurs (Rayon). Le web et Azure attendent le réseau : leur débit dépend de lui.

Sous le capot

Un seul binaire, trois sous-commandes. Chaque source a son moteur, puis tout converge vers la même détection et les mêmes exports. Schéma simplifié.

  • Traitement au fil de l'eau, pour garder une faible empreinte mémoire.
  • Profil release optimisé : LTO, une seule unité de compilation, symboles retirés.
  • Sur le web : suivi des liens jusqu'à une profondeur donnée, en-têtes personnalisés (authentification), filtre d'URL par expression régulière, téléchargement optionnel.
  • Binaires Windows et Linux publiés ; compilation croisée depuis Linux documentée.
