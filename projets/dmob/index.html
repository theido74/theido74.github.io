Comment c'est construit

  • Chaque appli est un projet Gradle indépendant (Kotlin DSL), avec son catalogue de versions.
  • Une activité principale par appli, une interface déclarative en Jetpack Compose et un thème Material 3 : couleurs, typographie, thème.
  • Les tests d'exemple du gabarit Android Studio sont présents, unitaires et instrumentés.
  • Aucun serveur ni base de données n'apparaît dans l'arborescence.
